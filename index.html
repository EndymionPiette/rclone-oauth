MathDocs Rclone

A personal connection between Rclone and Google Drive for organizing and accessing my own documents on Linux.

What it does

I use Rclone on my own devices to access, mount and manage files in my personal Google Drive as part of a local document-management setup called MathDocs.

The OAuth application enables Rclone to request access to Google Drive after I authorize it with my own Google account. Depending on the permissions granted, Rclone may be able to access Drive files beyond the folder used for MathDocs.

Not a public service. This integration is intended for the Google account owner's personal use. This website does not provide a login, file hosting, public access to Drive, or access to the owner's files.

Privacy

This is an informational website only. It contains no analytics, forms, tracking scripts or application backend. See the privacy policy for details on data access and OAuth authorization.

About the software

Rclone is an independent open-source program. This site is not an official Google or Rclone website.
